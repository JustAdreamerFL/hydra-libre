Questions, answered

Good to
know.

What is Hydra Libre?+

Hydra Libre is an open-source desktop game launcher for Windows, Linux, and macOS. It organizes games you own, tracks playtime and achievements, and offers a local-first profile sync.

Do I need an account?+

No. You can use the local library, backups, and profile folder sync without an account. An account is only needed for optional online social features and Hydra Cloud.

Is profile synchronization free?+

Yes. Select a folder in Settings → Backups and Hydra Libre will keep a portable profile snapshot there. It works with any file synchronization service or a removable drive.

Which operating systems are supported?+

Hydra Libre releases are built for Windows, Linux, and macOS. Linux builds include AppImage and distribution packages where available.

Where can I report a problem or contribute?+

Open an issue or pull request on GitHub. Hydra Libre is built in the open and welcomes bug reports, translations, design ideas, and code contributions.
